# 백테스트

`docs/rules/*.json` 의 기대값을 실측한다. 앱·스캐너와 **같은 규칙 파일**을 읽으므로,
여기서 나온 숫자가 곧 실전에서 쓰는 규칙의 숫자다.

## 실행

시장 데이터를 받아야 하므로 인터넷이 되는 곳에서 돌린다.
**단계별 절차·결과 읽는 순서·트러블슈팅은 [RUNBOOK.md](RUNBOOK.md) 에 있다.**
Colab 으로 돌리려면 [colab.ipynb](colab.ipynb) 를 연다.

### PC에서 직접

```bash
pip install -r scanner/requirements.txt

# 1) 먼저 빠른 점검 — 30종목·2년·스윕 생략. 2~5분이면 끝난다.
python backtest/run.py --market us --quick

# 2) 정상 동작을 확인했으면 본 실행
python backtest/run.py --market us --start 2019-01-01 --split 2024-01-01
python backtest/run.py --market kr --universe 150
```

본 실행은 미장 30분~1시간, 국장 1~2시간 정도 걸린다(종목 수·네트워크에 따라).
일봉은 과거분이 바뀌지 않으므로 `backtest/cache/` 에 캐시되어 재실행은 훨씬 빠르다.

결과물 `docs/backtest_us.md` 를 열어보거나, 저장소에 커밋하면 앱 일지 탭의
'룰셋 검증' 카드에 자동으로 표시된다.

### GitHub Actions

Actions 탭 → **백테스트** → Run workflow. 결과가 실행한 브랜치에 커밋된다.

> `workflow_dispatch` 워크플로는 **기본 브랜치(main)에 파일이 있어야** Actions 탭에
> 나타난다. 기능 브랜치에만 있으면 버튼이 보이지 않는다.

| 옵션 | 설명 |
|---|---|
| `--quick` | 30종목·2년·스윕 생략. 본 실행 전 파이프라인 확인용 |
| `--limit N` | 유니버스를 N종목으로 제한 |
| `--no-sweep` | 파라미터 스윕 생략 (가장 오래 걸리는 단계) |
| `--split` | 학습/검증 분할 기준일 (기본 2024-01-01) |
| `--universe N` | 국장 분기별 상위 N종목 (기본 200) |

## 무엇을 측정하는가

1. **현행 룰셋 성과** — 지금 앱에 들어 있는 가중치로 매매했을 때.
2. **기준선** — 52주 고점 근접 + 거래량 증가만 보고 전부 진입했을 때.
   룰셋이 이 기준선보다 나아야 존재 의미가 있다.
3. **무엇이 신호를 탈락시키는가** — core 항목별 탈락 비율. 규칙이 너무 빡빡해
   매매가 안 나올 때 원인을 지목한다.
4. **항목별 판별력(lift)** — 각 항목이 충족일 때와 아닐 때의 평균 R 차이.
   `|t| ≥ 2` 가 아니면 우연과 구분되지 않으므로 가중치 근거로 쓰지 않는다.
5. **제안 가중치** — 유의한 양의 lift 에 비례해 재배분. 총합은 현행과 같게 유지한다.
6. **과최적화 검증** — 학습기간 가중치를 검증기간에 그대로 적용해 유지율을 본다.
   60% 미만이면 그 가중치는 과거에만 맞는 숫자이므로 앱에 반영하지 않는다.
7. **파라미터 스윕** — 손절폭·추적방식·익절 R 등을 바꿔가며 비교.

## 방법론

**룩어헤드 금지.** t일 종가까지의 데이터로만 판정하고 체결은 t+1일 시가로 한다.
지표 계산에 넘기는 프레임은 항상 `df.iloc[:t+1]` 로 자른다. 데이터를 임의 시점에서
잘라내고 다시 돌렸을 때 그 이전 신호가 완전히 동일한지 검증했다.

**갭 반영.** 손절가 아래에서 갭 하락하면 시가에 체결된다. 진입 당일의 남은 장중
움직임도 검사하므로, 진입 직후 무너지는 경우가 누락되지 않는다.

**R 단위 손익.** 계좌 크기·수수료 가정에 결과가 좌우되지 않게 한다.
`R = (청산가 − 진입가) / (진입가 − 최초 손절가)`, 분할 청산은 비중 가중 합.

**생존편향** — 국장은 각 분기 시점의 거래대금 상위 종목을 그 시점 기준으로 뽑으므로
지금 상장폐지된 종목도 들어온다(편향 없음). 미장은 무료 소스로 시점별 지수 구성을
얻기 어려워 현재 구성종목을 쓴다(**편향 있음** — 리포트에 경고가 붙는다).

## 알려진 한계

- **국장 수급 지표**(거래대금 상위 유지일수, 외국인·기관 연속 순매수)는 과거 재현
  비용이 커서 판정 불가로 둔다. 해당 core 항목이 자동 충족되지 않으므로 국장 룰셋
  통과 문턱이 실전보다 높다. 국장 결과는 보수적으로 읽어야 한다.
- 수수료·세금·슬리피지 미반영. 실제 성과는 이보다 낮다.
- 스윕 결과에서 최고값을 그대로 고르는 것 자체가 과최적화다. 성과가 평평한 구간의
  중앙값을 고르는 편이 안전하다.
